# N26 — 德国数字银行

> 目前中国大陆居民唯一能远程开通的德国银行账户。

## 基本信息

| 项目 | 详情 |
|------|------|
| 总部 | 德国柏林 |
| 类型 | 数字银行（持德国银行牌照） |
| 卡种 | Mastercard（虚拟卡 + 实体卡） |
| 货币 | 欧元（EUR）为主，支持多币种转账 |
| 收款 | 德国 IBAN，支持 SEPA + SWIFT |
| 监管 | BaFin（德国联邦金融监管局） |
| 账户类型 | Standard（免费）/ Smart（月费）/ You / Metal |
| 存款保障 | 最高10万欧元（德国存款保障计划） |
| IBAN | DE 开头的德国个人 IBAN |
| 货币转换费 | **免**（万事达实时汇率） |
| 境内消费 | 可绑定微信/支付宝 |
| 加密货币 | 友好，可用于 web3 出入金 |
| 券商出入金 | 支持 IB 等券商 |
| 地址证明 | N26 月结单可作为地址证明 |

## 核心功能（2026年5月更新）

### 1. 境外支付通用底卡
- 正经的德国 Mastercard，过卡率高
- 几乎所有海外 SaaS、订阅、电商都能刷
- 直接用卡号也能过大部分场景，无需 Apple Pay

### 2. 汇款到支付宝（新功能）
- 路径：Send Money → Foreign Currency Transfer → 收款货币 CNY → Alipay
- 底层走 Wise 合作通道
- 到账时间：约30分钟
- 手续费：约0.5%（按金额比例）
- 汇率：Wise 中间价
- 填写：收款人姓名拼音 + 支付宝账号
- 意义：实现欧元→人民币完整闭环

### 3. 网页端订阅海外服务
- 适用于 Claude、ChatGPT Pro、Cursor、X Premium、Replit、Notion 等
- 关键技巧：**账单地址写欧洲**（与发卡国一致，Stripe 风控通过率高）
- 之前方案：N26 虚拟卡 + Apple Pay + iOS 端支付（繁琐）
- 新方案：直接网页端支付，一次过

### 4. 欧元入金嘉信（投资）
- N26 → Wise（SEPA转账欧元）→ Wise美元账户 → ACH到嘉信
- 欧元兑换成本比港币更低，全程接近无损

### 5. 小额海外收款
- 自带德国 IBAN
- SEPA：欧元区内免费、当天到账
- SWIFT：支持非欧元区收款
- 适合：自由职业、内容创作、独立开发、跨境小活

### 6. App 内买卖全球资产
- 覆盖 5000+ 股票和 ETF
- 含美股大盘、纳斯达克100、欧洲蓝筹、主题ETF
- 交易手续费：0欧元
- 最低1欧元起买，支持碎股交易
- 可直接定投 MSCI World 或 S&P 500 ETF

## 开户准备

| 材料 | 要求 |
|------|------|
| 护照 | 中国护照，有效期内 |
| 境外手机号 | 推荐 Giffgaff（英国），不建议用接码平台 |
| 国际邮箱 | Gmail 或 Outlook，勿用 QQ/163 |
| 欧洲地址 | 德国或奥地利真实地址（Google地图可找），无需地址证明 |
| 网络环境 | 建议对应开户地区 IP |

## 注册流程

### 方案A：德国区（需视频验证）
1. 下载 N26 App（苹果需非国区 Apple ID）
2. Open Account → 选德国或奥地利（不需当地税号）
3. 填写邮箱、姓名、出生日期、国籍（China）
4. 选 Standard（免费）
5. 填写欧洲地址
6. 绑定境外手机号
7. 身份验证：视频验证（Video Ident）

### 方案B：奥地利区（免视频验证，推荐）

> 英语不好或不想视频验证的首选。全程拍照上传护照 + 人脸识别。

**准备：** 境外手机号 + Gmail + 奥地利地址（无需证明）+ 护照

**步骤：**
1. 下载 N26 App（苹果需外区账号，安卓 Google Play）
2. 选地区 **Austria**（奥地利）
3. 输入邮箱 → 开通知
4. 姓名（拼音）、出生日期、性别、国家选中国
5. 城市填拼音，填邀请码
6. 设密码 → 创建账户
7. 地址选奥地利住宅地址
8. 商业用途 → No → 个人账户
9. 工作情况（全职、行业自选）→ 收入来源 → 月收入 → 国家选中国
10. 用途选"网上购物"
11. 护照验证：拍照上传（第二张斜着拍）+ 人脸识别
12. 位置信息允许 → 签署文档 → 短信验证码

**审核时间：** 工作日十几分钟，非工作日约2小时

**审核通过后：**
1. 奥地利税号选 Later（不填也不关户）
2. 美国税号 → No
3. 中国税号填身份证号
4. 账户类型选 Standard（两步都别点绿色按钮，选上面的）
5. 选虚拟卡 → 绑定 Apple Pay

**入金激活：** 用 Wise 转50欧到 N26 的 IBAN（DE开头），免费且秒到

## 汇款回国

欧元→人民币完整方案见 [eur-to-cny-transfer](foreign/concepts/eur-to-cny-transfer.md)。

## 视频验证（Video Ident）

- 时长：5-10分钟，真人客服，英语
- 时间：北京时间下午4点后（德国工作时间）
- 流程：确认本人 → 展示护照 → 读护照号 → 报出生日期 → 输入验证码
- 技巧：英语不好可用翻译耳机；听不懂可关闭重来（无次数限制）
- B站有全程录音视频可预习

## 费用参考

| 账户类型 | 月费 | 实体卡 | 主要区别 |
|----------|------|--------|----------|
| Standard | 免费 | 无（仅虚拟卡） | 基础功能 |
| Smart | €4.90/月 | 有 | 保险、分类统计 |
| You | €9.90/月 | 有 | 旅行保险、免外币手续费 |
| Metal | €16.90/月 | 金属卡 | 全部权益 + 现金返还 |

> 技巧：先开通一个月 Smart 拿实体卡，再降回 Standard。

## 港卡替代？

N26 功能越来越完整，部分场景可替代港卡。但如果需要港卡，[ccb-asia](foreign/entities/ccb-asia.md)（建行亚洲）是一个无管理费、可线上开户的选择。

## 风险提示

- **政策风险：** BaFin 合规审查 + 欧盟 KYC 收紧，窗口可能缩小
- **地址审查：** 老用户可能被要求补材料证明居住地址
- **建议：** 能开尽早开，开了尽早用
