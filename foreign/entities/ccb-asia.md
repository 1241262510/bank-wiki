# 建行亚洲（CCB Asia）

> 香港建行亚洲，可线上开户的港卡选择，无账户管理费。

## 基本信息

| 项目 | 详情 |
|------|------|
| 全称 | 中国建设银行（亚洲）股份有限公司 |
| 类型 | 香港持牌银行 |
| 卡种 | 银联双币卡（港元 + 人民币） |
| 账户管理费 | **无** |
| 跨境取现 | 内地建行柜员机取现无跨境取现手续费 |
| 跨境支付 | 支持跨境支付通 |
| 开户方式 | 线下（分行现场）+ 线上（香港境内APP） |
| 所需材料 | 身份证 + 港澳通行证 |

## 与其他港卡对比

| | 建行亚洲 | 中银香港 | 汇丰One |
|--|---------|---------|---------|
| 账户管理费 | **无** | 无 | 需留存1万港币免管理费 |
| 线上开户 | 支持 | 通过率低 | 支持 |
| 跨境取现手续费 | **无** | 有 | 有 |
| 投资账户 | 线上开户不自带 | 自带 | 自带 |
| 开户难度 | 低 | 中 | 低-中 |

## 线下开户

### 预约方式
- 建行亚洲公众号 → 服务申请 → 预约服务
- 或官网预约页面

### 必备材料
- 身份证
- 港澳通行证
- "准许逗留"入境小票
- 地址证明

### 按用途追加材料

| 用途 | 追加材料 |
|------|----------|
| 港美股投资 | 在职证明、工资流水、银行存款、社保证明、投资证明 |
| 交保险 | 保险合同、保费缴费通知书 |
| 留学 | 录取通知书、学费通知书 |

> 实际要求因客户经理而异，尽量准备齐全。

## 线上开户（推荐）

> 必须人在香港境内，不支持科技上网或修改定位。

### 前置准备

| 准备项 | 说明 |
|--------|------|
| 下载APP | 提前下载建行亚洲APP，检查能否运行 |
| 手机漫游 | 开通漫游以收短信验证码 |
| 网络环境 | 必须用香港WIFI或香港手机号网络（内地流量包不行） |
| NFC功能 | 手机必须有NFC |
| 出入境记录 | 小程序"移民局12367"下载PDF |
| 备用手机 | 建议多带一台 |
| 证件有效期 | 身份证 + 港澳通行证 ≥ 30天 |

### 开户步骤

1. e账户服务 → 开立户口 → 内地身份证
2. 勾选：港元 + 多货币储蓄户口 + 定期存款
3. 扫描身份证 → 读取港澳通行证 → 上传出入境记录
4. 人脸识别（可能需反复尝试）
5. 填写个人信息（出生地、地址、邮箱、手机）
6. 填写就业信息（状态、职业、年收入）
7. 选分行 + 提款卡领取方式（可选寄往通讯地址）
8. 设网银用户名和密码 → 提交

### 审核结果

**当场成功：** 收2封邮件 → 几天后短信通知可用

**未当场成功：** 等待审核（可能数天到2个月），期间可能来电核实

**实例时间线：**
```
2026.01.13  提交申请
2026.03.11  审核通过（2个月）
2026.03.25  账户可用
2026.04.13  收到银行卡 + 密码信
全程：约3个月
```

## 收卡与激活

- 银行卡和密码信**分开平邮**寄出，约3-6周送达
- 平邮无法追踪，建议联系当地邮局送信人
- 激活：APP"银联双币卡"中激活
- 改密：**必须到香港建行亚洲柜员机**修改（不支持内地）

## 补签名与投资账户

- 线上开户**没有投资账户**
- 投资账户只影响银行内理财，不影响转账到券商
- 如需加开投资账户 → 去网点补签名 → 客户经理可能要求社保、工资流水等

## 延伸阅读

持有外币卡后，可能需要 **us-card-forwarding|美卡转寄回国** 的知识。

## 适合人群

- 想要港卡但中银线上通过率低、汇丰要管理费
- 需要内地柜员机无手续费取现
- 希望线上开户、材料简单
- 不急需投资账户功能
