## 关于N26要求填写税号

税号的问题专门咨询了客服，客服回复目前不填也不会关户，哪天不能用了再说吧。

## 德国N26银行简介及优点

N26 Bank SE（原Number26），2013年创立于德国柏林，是欧洲头部的线上数字银行，持有德国BaFin与欧洲央行颁发的全银行牌照，资金可享受最高10万欧元的德国存款保障，办理后可获得"DE"开头的德国个人IBAN账户。

- 标准账户完全免费，提供免费虚拟卡，可绑定Apple Pay
- 全球消费免货币转换费，按万事达实时汇率结算
- 支持绑定微信支付宝，可境内消费使用
- 支持SEPA转账，欧元区转账丝滑
- 可与Wise无损转账且秒到

## N26的几个用途

1. 可用于IB等券商出入金
2. 加密货币友好，可用于web3出入金
3. 可用于订阅各种AI会员
4. 提供地址证明（N26月结单可用于注册德区CB等）
5. 可积累德国信用，后期可尝试申请德国信用卡

## 申请准备资料

1. 境外手机号（香港的也可以，大陆手机号目前无法收到验证码）
2. 境外邮箱（Gmail，不要用国内邮箱）
3. 奥地利住宅地址（无需地址证明）。英语好也可用德国地址，但多一个客服视频验证环节
4. 护照
5. 网络环境（不需要完全与申请地对应，US即可）

## 申请流程（奥地利区，无视频验证）

1. 下载N26 APP（苹果需外区账号，安卓用Google Play）
2. 选择地区为 Austria 奥地利
3. 输入邮箱
4. 打开通知（Enable）
5. 填写姓名（拼音）、出生日期
6. 性别（建议不要选第三个）
7. 国家选择中国
8. 城市填拼音，Redeem a code 填入邀请码
9. 设置密码，创建账户
10. 地址选择奥地利住宅地址
11. 是否商业用途 → 选 No
12. 继续个人账户（选绿色按钮上面的 Continue）
13. 工作情况 → 全职，行业自行选择
14. 收入来源 → 选第一个
15. 月收入
16. 收入来源国家 → 中国
17. 用途 → 网上购物
18. 护照验证 → 拿出护照拍照
19. 地区选中国 → 选择护照
20. Place of birth 按护照填写（一般是省份）
21. 人脸识别 + 护照拍摄（第二张需斜着拍）
22. 位置信息点允许
23. 签署申请文档
24. 输入短信验证码
25. 申请流程结束，等待审核

**审核时间：** 工作日快的话十几分钟，非工作日约两小时

## 审核通过后继续

1. 奥地利税号选择稍后提供（Later）
2. 是否有美国税号 → No
3. 添加中国税号 → 填身份证号
4. 账户类型选标准 Standard（两步都不要点绿色按钮，选上面的）
5. 选择虚拟卡
6. 绑定虚拟卡到 Apple Pay（可能需多试几次）

## 用Wise给N26入金激活

1. N26首页点 ADD 查看账户详情，里面有IBAN（DE开头）
2. Wise与N26互转免费且秒到
3. Wise注册：身份证注册填中文姓名，护照注册填拼音
4. Wise中添加欧元账户 → 兑换50欧元 → 汇款到N26的IBAN
5. 马上到账
