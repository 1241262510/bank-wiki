# 美卡转寄回国指南

> 用 Pirateship 以 UPS 官网 1/5 的价格把美国信用卡转寄回国。

## 背景

玩美卡（如 Capital One）成功批卡后，需要把卡片从美国地址转寄回国。如果租用的是 AMTB 地址，房东通常推荐 DHL，一张信用卡可能被收 $100~200 快递费。

## 官方快递价格对比（亚利桑那→深圳）

| 快递 | 网点自投 | 上门取件 | 特点 |
|------|---------|---------|------|
| DHL | $98.61 | $115.05 | 房东常用，贵 |
| UPS | $132 | $154 | 官网最贵 |
| USPS | 统一价 | 统一价 | 价格中等 |

> 以上为官网报价参考，不同城市有差异。

## 最优方案：Pirateship（海盗船）

| 项目 | 说明 |
|------|------|
| 网站 | www.pirateship.com |
| 承运商 | UPS（下单后可在 UPS 官网追踪） |
| 价格 | 约 UPS 官网的 **1/5** |
| 支付 | PayPal / Venmo / Visa / Mastercard / AE |
| 注册 | 需要梯子，免费注册 |

### Pirateship 打单流程

```
注册账号 → 创建标签 → 填收件地址 → 填重量和类型
→ Get Rates 获取价格 → 选工作日（周末有额外费用）
→ Buy Label → 支付 → 生成标签（含1Z追踪号）
```

### 注意事项

| 要点 | 说明 |
|------|------|
| 打单时间 | **选工作日**，周末有额外费用 |
| 商业发票 | UPS 清关严格，建议附上 Commercial Invoice |
| 发票模板 | UPS 官网可下载 |
| 跑腿费 | AMTB 房东可能收 $5，私人地址看房东 |
| 费用争议 | Pirateship 发起争议一般能退款 |
| 自己打单 | 比让房东打单更好（省钱+可争议+优化账单） |

## 交给房东

把标签 PDF + 发票 PDF 发给房东，让他贴在信封上一起寄出。

## 追踪物流

谷歌搜索 UPS → 输入标签上 "1Z" 开头的转运编号 → 查询进度（一般一天更新一次）。

## 不推荐的做法

| 做法 | 风险 |
|------|------|
| 让房东帮忙打单 | 收打单费，且无法自己发起费用争议 |
| 首卡直接 Replace 到中国地址 | 可能被银行认定为欺诈 |
| 不贴发票 | 海关可能扣件，耽误更多时间 |
